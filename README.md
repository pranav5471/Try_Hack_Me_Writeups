## 💡 About the SOC Level 1 Role

A SOC Level 1 analyst is the first line of defence in any organisation. Through this path I have developed an understanding of what that role demands:

- **Monitoring** — Reviewing event logs and alerts in a 24/7 SOC environment
- **Triage** — Distinguishing real threats from false positives quickly and accurately
- **Escalation** — Handing off confirmed threats to L2/L3 analysts with clear documentation
- **Investigation** — Pivoting on IOCs to understand attacker infrastructure and intent
